Площадь проектируемой площадки

Границы сняты с твоего чертежа (красный контур), размеры в сантиметрах → перевёл в метры. Контур замкнулся точно, диагонали сошлись.

≈ 111,7 м² (по чертежу 111,66 м²; твои замеры рулеткой это подтвердили — для сметы бери 112 м² с запасом)

Проверка твоими замерами — всё сошлось

Три независимых замера рулеткой (правая сторона + две диагонали между дальними углами) сравнил с тем, что даёт контур. Везде совпадение ~2–3% — форма и масштаб верные:

ЗамерТы намерил, мПо контуру, мРазница
Правая сторона (ворота 4,00 + 7,30)11,3011,511,8%
D1 (дальние углы: низ-лево → верх-право)15,715,32,5%
D2 (дальние углы: верх-лево → низ-право)20,821,53,4%

Разница в пару процентов — норма для реального участка: углы не идеально прямые, рулетка «плюс-минус». На итог по площади это влияет в пределах ±1,5 м².

Уточнения получены — всё подтвердилось

Правая сторона — прямая линия длиной 11,30 м (проём ворот 4,00 + участок 7,30). Совпала с контуром (11,5 м) в пределах 2%.

Диагонали — замерены «на глаз», между дальними углами, для понимания. Обе легли в контур с точностью 2–3%, отдельный геодезический пересчёт не нужен.

Итог: площадь ≈ 111–112 м². Для заказа материалов бери 112 м² — небольшой запас лишним не будет.
